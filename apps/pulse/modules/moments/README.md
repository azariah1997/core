# moments

Private saved-highlights timeline of meaningful interactions (spec §30-31) - explicitly not a chat history, no message content, just references to interactions plus participants/timestamp/duration. Stores references, never duplicates interaction payload.

**Owns:** `moments` table (references `interactions.id`, never duplicates its content). Each row is one participant's personal bookmark, not a shared record - the two people in the same interaction each get their own independent row (unique per `(saved_by_user_id, interaction_id)`), matching how "save"/bookmark features work in every consumer product this pattern is modeled on. Re-saving the same interaction is idempotent (same row returned, no duplicate). No auto-expiry: unlike Mood's deliberate daily decay, a Moment's entire purpose is durability, so "retention" here just means the explicit `DELETE`.
**Depends on:** `pulse-interactions`, consumed in-process via the same `pulsemodules` adapter pattern used by signals→pulse-interactions (Phase 11) and mood/live-touch→bond (Phase 8/10) - `moments.Service.Save` resolves the real interaction through `pulseinteractions.Service.Get`, which already enforces sender/receiver-only access, so Moments never re-implements a participation check. Only a `completed` interaction can be saved.
**Endpoints:** `POST /v1/pulse/moments/{interactionId}/save`, `GET /v1/pulse/moments`, `DELETE /v1/pulse/moments/{id}`.
**Status:** implemented - Phase 12 (Moments). Live-validated end to end with the real Alice/Bob/Carol sample users against real Postgres: Alice saving a real completed Signal interaction, Bob independently saving the same interaction to his own list with the perspective-correct other-participant ID, a real 403 rejecting a non-participant's save attempt, idempotent re-save returning the same moment, and a real delete/re-list round trip. Mobile ships a real Moments tab (list with gentle "N little moments together this week" stat computed client-side, per spec §32 - never a punishing streak counter - plus per-row delete) and a "Save this moment ♥" button wired into both the Home tab (after a Pulse or Knock completes) and the Signals screen (after a Signal send). Real source in `apps/pulse/api/internal/moments/`.
